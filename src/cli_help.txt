
Lightweight Event Manager — terminal log collection and search

Usage: loglem [OPTIONS] [COMMAND]

Commands:
  diagnostics        Read persistent Loglem errors, cause chains, and stack traces
  web                Raccoglie i log e apre l'interfaccia web (se il servizio è attivo, ne mostra l'indirizzo)
  tui                Open the keyboard-driven terminal interface (also the default)
  init               Create an empty configuration
  add                Aggiungi un log con il percorso guidato (cosa, chi, dove, riepilogo)
  site               Create, list or inspect sites and projects
  source             Configure sources without opening an interface
  podman-list        List Podman containers and their pods
  discover           Cerca i log nelle configurazioni dei programmi conosciuti (src/recipes)
  docker-list        Elenca i container Docker
  kubernetes-list    Elenca i pod di Kubernetes in tutti i namespace
  status             Show archive locations, sizes, dates, and collection status
  collect            Collect once and enforce archive retention
  check              Controlla che Loglem giri e che le sorgenti vengano lette. Esce con codice 1 se c'è un problema: utilizzabile da cron, systemd o un programma di monitoraggio
  tail               Mostra le righe nuove appena arrivano (in locale, o da un altro computer con --server)
  backup             Copia coerente di configurazione e archivi in una cartella nuova
  backup-verify      Verifica un backup: impronte, integrità SQLite, righe. Esce con codice 1 se non è valido
  restore            Ripristina un backup verificato (Loglem deve essere fermo)
  erase              Cancella i dati di una persona (GDPR art. 17) da tutte le sorgenti. Senza --apply mostra solo quante righe toccherebbe. Non tocca i file originali né i backup
  export             Esporta i dati di una persona (GDPR art. 15) in un file di testo o JSON
  audit              Chi ha cercato, esportato o cancellato, e quando (ultimi giorni)
  stats              Statistiche di un log di accesso: richieste per giorno, pagine, codici, IP, lentezza
  advice             Cosa c'è nel log di una sorgente (IP, email, credenziali…) e cosa Loglem ti suggerisce, con i riferimenti di legge. Sono suggerimenti: verificali
  proof              Modalità prova: sigillo giornaliero con impronte concatenate e verifica
  privacy            Dati personali: mascheramento degli IP, campi JSON da tenere, rapporto
  alerts             Allarmi: regole, comando di notifica, «segna come visto»
  access             Accesso alla pagina web da altri computer: utenti e indirizzo
  serve              Servizio: raccoglie i log e serve l'interfaccia web finché non riceve SIGINT o SIGTERM
  search             Literal, case-sensitive text search; dates are UTC unless a timezone is supplied
  prune              Preview expired entries, or delete them with --apply
  archive-completed  Archive a file explicitly handed off by a producer that has CLOSED it
  config             
  service            
  update             
  self-check         Test the executable and embedded SQLite schema without changing user data
  help               Print this message or the help of the given subcommand(s)

Options:
      --data-dir <DATA_DIR>  [env: LOGLEM_DATA_DIR=]
  -h, --help                 Print help
  -V, --version              Print version

tail

Usage: loglem tail [OPTIONS]

Options:
      --data-dir <DATA_DIR>
          [env: LOGLEM_DATA_DIR=]

      --source <SOURCE>
          Solo questa sorgente

      --text <TEXT>
          Testo da cercare (vuoto = tutto)
          
          [default: ""]

      --ignore-case
          Non distinguere maiuscole e minuscole

      --level <LEVEL>
          Solo righe di questa gravità o più gravi

          Possible values:
          - error:   Errori e più gravi
          - warning: Avvisi, errori e più gravi

      --ip <IP>
          Solo righe che contengono questo indirizzo IP

      --path <PATH>
          Solo richieste a questo percorso (es. /login)

      --status <STATUS>
          Solo risposte con questo codice (es. 404)

      --server <SERVER>
          Indirizzo della pagina web del server, es. http://10.0.0.1:8790

      --user <USER>
          Utente con cui entrare nel server (la password viene chiesta)

      --history <HISTORY>
          Quante righe recenti mostrare prima della diretta (solo in locale)
          
          [default: 10]

  -h, --help
          Print help (see a summary with '-h')

erase
Cancella i dati di una persona (GDPR art. 17) da tutte le sorgenti. Senza --apply mostra solo quante righe toccherebbe. Non tocca i file originali né i backup

Usage: loglem erase [OPTIONS]

Options:
      --data-dir <DATA_DIR>
          [env: LOGLEM_DATA_DIR=]

      --source <SOURCE>
          

      --text <TEXT>
          Testo da cercare (vuoto = tutto)
          
          [default: ""]

      --ignore-case
          Non distinguere maiuscole e minuscole

      --level <LEVEL>
          Solo righe di questa gravità o più gravi

          Possible values:
          - error:   Errori e più gravi
          - warning: Avvisi, errori e più gravi

      --ip <IP>
          Solo righe che contengono questo indirizzo IP

      --path <PATH>
          Solo richieste a questo percorso (es. /login)

      --status <STATUS>
          Solo risposte con questo codice (es. 404)

      --reason <REASON>
          Perché si cancella, per il registro (es. «richiesta art. 17 del 17/11/2026, pratica 3»)

      --originals
          Cancella anche dai file originali (solo file finiti e già archiviati)

      --apply
          Esegue davvero la cancellazione

  -h, --help
          Print help (see a summary with '-h')
